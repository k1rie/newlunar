# NewLunar - Remake de la Landing Page de Lunar Client

---

### 🚀 [Ver Demo en Vivo](https://k1rie.github.io/newlunar/)

Este proyecto es una recreación fiel y detallada de la landing page de Lunar Client, desarrollado puramente con HTML y CSS. El objetivo principal fue replicar un diseño profesional existente desde una maqueta de Figma, poniendo a prueba mis habilidades de maquetación, atención al detalle y dominio de CSS moderno.

---

## 🎨 Diseño y Objetivo

El diseño se basó en una maqueta de Figma, con el fin de lograr una réplica "pixel-perfect" de la interfaz original. El proyecto se centró en los siguientes objetivos:

* **Maquetación desde Figma:** Traducir un diseño de alta fidelidad a código semántico y bien estructurado.
* **CSS Moderno:** Utilizar técnicas como Flexbox y/o CSS Grid para crear un layout robusto y escalable.
* **Diseño Responsivo:** Asegurar que la landing page sea completamente funcional y visualmente atractiva en diferentes tamaños de pantalla, desde dispositivos móviles hasta escritorios.
* **Atención al Detalle:** Replicar con precisión la tipografía, los colores, el espaciado y los elementos visuales del diseño original.


---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Se utilizó HTML semántico para estructurar el contenido de manera clara y accesible.
* **CSS3:** Se emplearon técnicas avanzadas de CSS, incluyendo:
    * Flexbox y CSS Grid para el layout.
    * Variables CSS para una gestión de colores y temas más sencilla.
    * Media Queries para el diseño responsivo.
